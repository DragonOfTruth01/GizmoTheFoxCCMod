# Summary

This mod adds the following:

- <b>1</b> Character
- <b>66</b> Cards
  - <b>10</b> common
  - <b>8</b> uncommon
  - <b>6</b> rare
  - <b>30</b> potions
  - <b>10</b> generated cards
  - <b>1</b> status
  - <b>1</b> EXE cards
- <b>10</b> Artifacts
  - <b>1</b> starter
  - <b>6</b> common
  - <b>3</b> boss
- <b>4</b> Statuses

Dialogue and card art to be added!
